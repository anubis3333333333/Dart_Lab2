ВОПРОСЫ:

1. Поле класса принадлежит самому объекту (или классу) и существует в памяти всё время, пока жив этот объект, позволяя сохранять его состояние между вызовами разных методов, тогда как обычная переменная внутри функции является локальной, создаётся в момент вызова функции и полностью уничтожается сразу после её завершения.2. Конструктор — это специальный метод класса, который автоматически вызывается при создании нового объекта и нужен для того, чтобы инициализировать начальное состояние объекта, то есть задать значения его полям при рождении.3. Аннотация @override перед toString() указывает компилятору, что мы намеренно переопределяем стандартный метод базового класса Object своим собственным полем или логикой, а если её убрать, программа всё равно будет работать, но мы потеряем защиту от случайных ошибок (например, если мы опечатаемся в имени метода, компилятор без @override не предупредит нас, что мы создали новый метод вместо переопределения старого).4. Статическое поле static int \_counter принадлежит самому классу, а не его конкретным экземплярам, поэтому оно является общим для всех объектов этого класса, и в программе всегда существует ровно одна копия этого поля, в отличие от обычного поля, копия которого создаётся заново для каждого нового объекта.5. Нижнее подчёркивание в начале имени переменной \_counter в языке Dart означает приватность (private), то есть это поле становится скрытым и доступным для использования только внутри того файла (библиотеки), где данный класс описан, и его нельзя напрямую вызвать или изменить из других файлов проекта.
